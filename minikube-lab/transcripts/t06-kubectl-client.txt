== addendum: who hid the token? ==
In the config view output above, the token shows as <redacted> — that is kubectl itself:
writing 'kubectl config view --minify' straight to a file and counting gives 0 occurrences
of the token in the view output, while the kubeconfig file itself contains it once,
in plain text. Moral: config view is safe to show people; the file is a credential — guard it.
