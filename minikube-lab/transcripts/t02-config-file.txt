== addendum: where the config file really lives ==
With MINIKUBE_HOME set, minikube nests its state in a .minikube folder inside it.
The file is $MINIKUBE_HOME/.minikube/config/config.json and now contains:
{
    "cpus": "2",
    "driver": "docker",
    "kubernetes-version": "v1.37.0"
}
== a note on the default home ==
This shared lab machine already had a ~/.minikube from other work (dated 2026-10-17,
with a v1.31.0 kubectl/kubeadm cache) — which is why this lab kept its own state
inside MINIKUBE_HOME and never touched it.
